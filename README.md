# SixSortingHat - 육모자 사고 확장 앱

## 개요
여섯 색깔 모자 기법은 세계적인 컨설턴트이자 창의성 분야의 권위자인 에드워드 드 보노(Edward de Bono)가 개발한 사고 기법입니다. 
이 기법은 복잡한 문제에 대해 여러 사람이 동시에 다른 관점에서 생각하며 발생하는 비효율과 갈등을 방지하고, 
특정 시점에는 하나의 관점에만 집중하여 논의를 진행함으로써 보다 명료하고 생산적인 결과를 도출하기 위해 고안되었습니다.

참가자들은 여섯 가지 색깔로 구분된 가상의 '사고 모자'를 번갈아 쓰는 상징적인 행위를 통해, 
각 모자가 대표하는 특정 유형의 사고에만 집중하게 됩니다. 이를 통해 개인의 성향이나 감정에 치우치지 않고, 주제에 대한 다각적이고 균형 잡힌 탐색이 가능해집니다.

### 각 색깔의 모자는 다음과 같은 고유한 사고의 방향을 나타냅니다.
#### 하얀 모자 (White Hat): 정보와 사실
역할: 객관적인 정보와 데이터에 집중합니다.
주요 질문: "우리가 무엇을 알고 있는가?", "어떤 정보가 필요한가?", "이것은 사실인가, 아니면 가정인가?"
특징: 감정이나 의견을 배제하고 중립적인 입장에서 사실과 수치를 기반으로 사고합니다.

#### 빨간 모자 (Red Hat): 감정과 직관
역할: 직감, 감정, 예감 등 주관적인 느낌을 표현합니다.
주요 질문: "이 문제에 대해 어떻게 느끼는가?", "나의 직감은 무엇을 말하고 있는가?"
특징: 논리적인 근거나 설명을 요구하지 않고, 순수한 감정의 표현을 허용합니다. 이를 통해 논의에 인간적인 요소를 더하고, 중요한 직관을 포착할 수 있습니다.

#### 검은 모자 (Black Hat): 위험과 비판
역할: 잠재적인 문제점, 위험, 약점, 부정적인 측면을 찾아냅니다.
주요 질문: "무엇이 잘못될 수 있는가?", "가장 큰 위험 요소는 무엇인가?", "이 계획의 약점은 무엇인가?"
특징: 논리적인 근거에 기반한 비판적 사고를 통해 신중한 판단을 돕습니다. '악마의 변호인' 역할을 수행하며 잠재적 실패 가능성을 줄입니다.

#### 노란 모자 (Yellow Hat): 긍정과 낙관
역할: 아이디어나 제안의 긍정적인 측면, 이점, 기회를 탐색합니다.
주요 질문: "이것의 장점은 무엇인가?", "어떤 긍정적인 결과가 기대되는가?", "어떻게 실행 가능하게 만들 수 있는가?"
특징: 밝고 긍정적인 시각으로 가치와 가능성을 발견하고, 아이디어를 발전시킬 동기를 부여합니다.

#### 초록 모자 (Green Hat): 창의성과 새로운 아이디어
역할: 기존의 틀에서 벗어나 새로운 아이디어, 대안, 가능성을 제시합니다.
주요 질문: "다른 방법은 없을까?", "전혀 새로운 아이디어가 있는가?", "이것을 다르게 보면 어떨까?"
특징: 창의적이고 모험적인 사고를 장려하며, 브레인스토밍과 같이 자유로운 아이디어 생성을 촉진합니다.

#### 파란 모자 (Blue Hat): 사고의 관리와 통제
역할: 전체적인 사고 과정을 관리하고 통제하는 사회자 역할을 합니다.
주요 질문: "우리의 논의 목표는 무엇인가?", "지금 어떤 모자를 써야 할까?", "다음 단계는 무엇인가?"
특징: 회의의 시작과 끝을 주관하며, 논의의 방향을 설정하고, 다른 모자들의 사용 순서를 결정합니다. 오케스트라의 지휘자처럼 전체적인 사고의 흐름을 조율합니다.
