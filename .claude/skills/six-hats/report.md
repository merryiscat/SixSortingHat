# 최종 보고서 형식

마지막 생존 모자와 파랑이 **함께** 작성한다. 생존 모자는 내용의 깊이를, 파랑은 전체
균형과 구조를 책임진다. 탈락한 모자들의 기여를 빠뜨리면 보고서가 아니라 승자의 소감문이다.

## 구조

```
# 사고 확장 보고서: {주제}

## 1. 주제의 여정
처음 질문이 라운드를 거치며 어떻게 확장·재정의되었는가. 2~4문장.

## 2. 관점별 핵심 기여
모자별(탈락 모자 포함 5개)로 가장 가치 있었던 의견 1~2개씩.
어느 라운드 발언인지, 파랑 종합 점수는 몇이었는지 표기.

## 3. 확장된 아이디어 지도
토론에서 나온 방향들을 2~4개 갈래로 묶어 정리.
갈래마다: 핵심 내용 / 뒷받침 근거(검색 출처 포함) / 남은 불확실성.

## 4. 위험과 반론
검정의 기여를 중심으로, 각 갈래가 안고 있는 위험. 탈락 여부와 무관하게 다룬다.

## 5. 권고
생존 모자의 관점에서 가장 유망한 방향과 그 이유.
파랑이 덧붙이는 균형 노트 — 권고가 생존 모자의 성향에 치우친 부분이 있다면 명시.

## 6. 다음 단계
사용자가 바로 할 수 있는 행동 3~5개. 확인이 필요한 열린 질문 2~3개.
```

## 규칙

- 토론에 실제로 나온 의견만 쓴다. 보고서 단계에서 새 의견을 지어내지 않는다.
  (단, 5장의 "균형 노트"는 파랑의 종합 판단이므로 예외.)
- 점수를 인용할 때는 파랑 종합 점수를 쓴다.
- 검색으로 확인한 사실은 출처를 유지한다.
- 분량은 전체 토론의 1/3을 넘지 않는다. 보고서는 요약이지 재방송이 아니다.
