# **1. 목표 및 범위 정의 (Goal & Scope Definition)**

**참조 문서**: [docs/0_architecture.md](docs/0_architecture.md)

## **1.1 앱의 핵심 목표**

### **해결하려는 핵심 문제:**
- **사고의 편향성**: 개인이 단일 관점으로만 문제를 바라보는 한계
- **창의적 사고 부족**: 새로운 아이디어 발굴과 다각적 접근의 어려움
- **의사결정의 불완전성**: 충분한 검토 없이 성급한 결론에 도달하는 문제
- **토론의 비효율성**: 감정적 대립과 비구조적 논의로 인한 생산성 저하

### **제공하려는 핵심 가치:**
- **다관점 사고 지원**: 6가지 관점에서 동시에 문제를 분석하여 균형잡힌 시각 제공
- **창의성 촉진**: 체계적인 브레인스토밍과 아이디어 확장을 통한 혁신적 사고 지원
- **의사결정 품질 향상**: 사실, 감정, 위험, 기회 등 모든 측면을 고려한 종합적 판단 도구
- **AI 협업 경험**: 멀티 에이전트 시스템을 통한 새로운 형태의 인간-AI 협업 모델 제시

## **1.2 주요 타겟 사용자**

### **구체적 사용자 프로필:**

#### **1차 타겟: 창의적 사고가 필요한 일반 사용자 (20-40대)**
- **학생/연구자**: 논문 주제 선정, 연구 방향 설정, 문제 해결 아이디어 도출
- **직장인**: 프로젝트 기획, 업무 개선 아이디어, 문제 해결 방안 모색
- **창작자/기획자**: 콘텐츠 아이디어, 마케팅 전략, 창작 방향성 탐색
- **자기계발 관심자**: 개인 목표 설정, 진로 고민, 라이프스타일 개선

#### **2차 타겟: 전문적 의사결정이 필요한 사용자**
- **스타트업 창업자**: 비즈니스 모델 검증, 전략 수립, 리스크 분석
- **팀 리더/관리자**: 팀 운영 방안, 갈등 해결, 프로세스 개선
- **컨설턴트/기획자**: 클라이언트 문제 분석, 솔루션 도출, 제안서 작성

### **사용 상황:**
- **개인 브레인스토밍**: 혼자서는 떠올리기 어려운 다양한 아이디어가 필요할 때
- **중요한 의사결정**: 충분한 검토와 다각적 분석이 필요한 선택 상황
- **문제 해결**: 복잡하거나 새로운 유형의 문제에 직면했을 때
- **기획 및 전략 수립**: 체계적이고 종합적인 계획 수립이 필요할 때
- **학습 및 탐구**: 새로운 주제에 대한 깊이 있는 이해가 필요할 때

## **1.3 기능 범위 (Scope)**

### **포함할 기능 (MVP)**

#### **핵심 기능**
- **6개 모자 에이전트 시스템**: 각 색깔별 특화된 사고 방식으로 답변 생성
  - 하얀 모자: 객관적 정보와 데이터 중심 분석
  - 빨간 모자: 감정과 직관 기반 의견 제시
  - 검은 모자: 위험과 문제점 중심의 비판적 분석
  - 노란 모자: 긍정적 측면과 기회 발굴
  - 초록 모자: 창의적 아이디어와 대안 제시
  - 파란 모자: 전체 토론 관리 및 최종 종합

- **순차적 토론 시스템**: 각 모자가 이전 답변을 참조하여 점진적으로 확장
- **품질 검증 및 재순환**: 파란 모자의 품질 평가 기반 재토론 메커니즘
- **의도 분류**: 간단한 인사/정체성 질문과 복합적 사고가 필요한 질문 구분
- **실시간 스트리밍**: SSE를 통한 각 모자의 실시간 답변 전달

#### **결과물 제공**
- **그룹 채팅 형태 UI**: 6개 아바타가 순차적으로 발언하는 인터페이스
- **최종 종합 답변**: 파란 모자의 품질 검증을 거친 완성된 답변
- **토론 기록 저장**: 전체 대화 흐름과 각 모자별 기여도 추적

#### **기술 스택**
- **백엔드**: Python + FastAPI + LangGraph + GPT-4o-mini
- **프론트엔드**: 크로스플랫폼 모바일 앱
- **통신**: Server-Sent Events (SSE)
- **데이터**: PostgreSQL (체크포인터) + Redis (세션)

### **제외할 기능 (MVP에서)**
- **사용자 인증 시스템**: 무인증 방식으로 세션당 5코인 제공
- **결제 시스템**: 비용 제약 없이 품질 우선 운영
- **사용자 개입 기능**: 일방향 답변 수신만 지원 (파란 모자 역할 대행 불가)
- **다양한 LLM 모델**: GPT-4o-mini 단일 모델만 사용
- **멀티모달 입력**: 텍스트 기반 입력/출력만 지원
- **중간 과정 시각화**: 최종 결과물 시각화만 제공
- **협업 기능**: 개인 사용자 중심, 팀/그룹 기능 제외
- **고급 분석 도구**: 기본적인 토론 기록 외 상세 분석 제외

### **추후 고도화 계획**

#### **Phase 2: 사용자 경험 확장**
- **OAuth2 기반 SNS 로그인**: 개인화된 사용 이력 관리
- **사용자 개입 포인트**: 파란 모자 역할 수행, 토론 방향 제어
- **모자 순서 지정**: 사용자가 원하는 모자 순서로 토론 진행
- **중간 피드백**: 특정 모자에게 추가 질문이나 방향 제시

#### **Phase 3: 고급 기능**
- **D3.js 기반 시각화**: 토론 과정의 인터랙티브 논증 그래프
- **다양한 LLM 모델**: 각 모자별 특화 모델 적용
- **멀티모달 입력**: 이미지, 문서 업로드 지원
- **협업 모드**: 팀 단위 토론 세션 지원

#### **Phase 4: 비즈니스 확장**
- **기업용 버전**: 회의 지원, 의사결정 도구화
- **API 서비스**: 외부 시스템 연동을 위한 개발자 API
- **분석 대시보드**: 사용 패턴, 효과성 측정 도구

## **1.4 성공 지표**

### **정량적 지표**

#### **사용성 지표**
- **일일 활성 사용자 (DAU)**: 50명 이상 (1개월 후)
- **세션당 평균 질문 수**: 3개 이상
- **토론 완료율**: 85% 이상 (중간 이탈 15% 이하)
- **재방문율**: 70% 이상 (7일 내)

#### **품질 지표**
- **토론 평균 지속 시간**: 5-15분 (적절한 깊이 확보)
- **파란 모자 품질 통과율**: 80% 이상 (1차 검증)
- **사용자 만족도**: 4.0/5.0 이상 (앱스토어 평점)
- **평균 응답 시간**: 30초 이내 (모자별)

#### **기술 성능 지표**
- **시스템 응답 시간**: 95% 요청이 3초 이내
- **서버 가용성**: 99.5% 이상
- **동시 접속 처리**: 100명 이상 안정적 처리

### **정성적 지표**

#### **사용자 경험 지표**
- **창의성 향상 체감**: 사용자가 새로운 아이디어를 얻었다고 느끼는 정도
- **사고 확장 효과**: 기존에 생각하지 못했던 관점을 발견했다는 피드백
- **의사결정 도움**: 중요한 선택에 실제로 도움이 되었다는 증언
- **사용 편의성**: 직관적이고 간편한 인터페이스라는 평가

#### **혁신성 지표**
- **차별화 인식**: 기존 AI 채팅과 다른 독특한 경험이라는 평가
- **교육적 가치**: 6모자 사고법 자체를 학습하게 되었다는 피드백
- **추천 의향**: 타인에게 추천하고 싶다는 의견 비율

#### **장기적 가치 지표**
- **습관화**: 일상적 문제 해결 도구로 자리잡는 정도
- **사고 패턴 변화**: 실생활에서도 다관점 사고를 적용하게 되었다는 증언
- **커뮤니티 형성**: 사용자 간 경험 공유와 토론 문화 생성
